## Decrypt firmware image
Latasin aluksi https://github.com/robbins/tp-link-decrypt ohjelman repon git clone komennolla. Sitten latasin TapoV3 firmware binaryn ja kamera dump-tiedoston.
Aloitin dekryptaamalla firmware imagen:


`binwalk -e dump-tapo-c200v3-1.4.2.bin`
